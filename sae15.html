SAÉ 1.05 : Traiter des données

1. Contexte du projet

Ce projet marquait une étape importante de notre premier semestre : le passage à une autonomie complète dans la conception d'un programme informatique. L'objectif était de concevoir une application capable de centraliser, traiter et mettre en forme des données provenant de sources externes via des API (format JSON et XML). Au-delà de l'aspect purement fonctionnel, cette SAÉ exigeait une rigueur particulière dans la structuration du code, la gestion des erreurs et la documentation technique.

2. Compétences mobilisées

  • Programmation (R107) : Développement en Python avec une attention particulière portée sur la modularité du code et la gestion des structures de données complexes.
  • Interopérabilité et Web (R109) : Manipulation de requêtes API et parsing de formats de données standards (JSON, XML) pour extraire des informations pertinentes.
  • Traitement d'images : Utilisation avancée de la bibliothèque Pillow pour manipuler, assembler des tuiles cartographiques et intégrer des marqueurs dynamiques.
  • Méthodologie (R115) : Organisation du travail en binôme, rédaction d'une documentation technique claire en Markdown et formalisation d'un rapport de projet concis.

3. Analyse réflexive

L'aspect le plus stimulant de cette SAÉ a été la gestion de l'autonomie. Contrairement aux travaux dirigés classiques, nous avions la responsabilité de choisir les solutions techniques pour résoudre les problèmes rencontrés avec les API (ex: gestion des limites de requêtes ou des formats de données imprévus).

La manipulation des données brutes (JSON/XML) s'est révélée être un défi technique formateur, tout comme l'utilisation de la bibliothèque Pillow qui a nécessité une approche mathématique pour calculer correctement les coordonnées des tuiles. Ce projet a renforcé ma compréhension de la chaîne de traitement de l'information, de la récupération jusqu'à la visualisation finale.
